# AirCreator Frontend Studio

Estúdio 3D web interativo construído com Next.js, React Three Fiber e Tailwind CSS.

## Funcionalidades
- **Viewport de 4 Quadrantes**: Vistas ortográficas sincronizadas (Top, Front, Side) e perspectiva 3D livre com suporte a gizmos de manipulação.
- **Sobreposição de Blueprints**: Renderização de imagens de referência com controle de opacidade e alinhamento de eixos em tempo real.
- **Visualizador de Animações Cinemáticas**: Inspeção dos canais `CLA 0..31` (trem de pouso, ailerons, profundor, leme, rotação de hélice).
- **Inspeção de Topologia**: Exibição de wireframe, contagem de polígonos e anéis de seções transversais.
